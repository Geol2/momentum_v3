# 달빛 서랍 — Even Hub 스토어 등록 정보

포털 입력칸에 그대로 붙여 넣을 수 있게 정리했습니다. 글자 수 제한은 evenhub CLI 기준입니다.

## 이름 (1~20자)

```
달빛 서랍
```

- `evenhub/app.json`의 `name`, 안경 홈 화면 제목과 같아야 합니다(심사 항목).
- "Even"이 들어가면 자동 반려됩니다.

## 한 줄 소개 · tagline (1~50자)

```
영단어·SQLD 카드 복습과 오늘 할 일을 안경으로
```

## 설명 · description (1~2000자)

```
달빛 서랍은 휴대폰을 꺼내지 않고 안경으로 공부하고 하루를 챙기는 앱입니다.

■ 플래시카드 복습
- 영단어와 SQLD(SQL 개발자) 핵심 개념 카드가 들어 있습니다.
- 누르면 뜻이 보이고, 위로 쓸면 '알았음', 아래로 쓸면 '몰랐음'입니다.
- 몰랐던 카드는 이번 복습이 끝나기 전에 한 번 더 나옵니다.
- 잘 아는 카드는 1일, 3일, 7일, 15일 간격으로 점점 늦게 나와서 헷갈리는 카드에 집중할 수 있습니다.

■ 오늘 할 일
- 달빛 서랍 계정의 오늘 할 일을 안경에서 확인합니다.
- 누르면 완료 표시가 바뀌고, 웹·폰의 달빛 서랍에도 바로 반영됩니다.

■ 메모
- 고정한 메모와 오늘 메모를 안경에서 넘겨 봅니다.

■ 조작
- 위/아래로 쓸기: 이동
- 누르기: 열기, 뜻 보기, 완료 표시
- 두 번 누르기: 뒤로 가기 (첫 화면에서는 종료)

할 일과 메모를 보려면 휴대폰 화면에서 달빛 서랍 계정으로 로그인해야 합니다. 플래시카드는 로그인 없이 쓸 수 있습니다.
```

## 릴리스 노트 (ko, 1~3줄)

```
첫 버전입니다. 영단어·SQLD 플래시카드, 오늘 할 일 확인과 완료 표시, 메모 보기를 지원합니다.
```

## 권한 설명 (app.json과 동일)

- network → `https://api.geol2.com`
  > 달빛 서랍 계정의 오늘 할 일·메모·대화를 불러오고 저장하며, 음성 질문을 받아 적어 AI 답변을 받기 위해 달빛 서랍 서버에 접속합니다.
- g2-microphone (0.2.2부터 — 0.2.0은 이 권한이 없어 반려)
  > 안경을 눌러 말한 질문을 받아 적기 위해 안경 마이크를 씁니다. 누르면 켜지고 다시 누르면 꺼지며(한 번에 최대 60초), 녹음은 서버에서 받아 적은 직후 지우고 저장하지 않습니다.

## 개인정보 처리방침에 들어가야 할 내용

심사에서 "요청한 권한을 모두 다루고, 백엔드 도메인을 밝혀야" 합니다.

- 접속하는 서버: `https://api.geol2.com` (달빛 서랍 백엔드)
- 주고받는 데이터: 로그인 정보(이메일·비밀번호 → 인증 토큰), 할 일, 메모, AI 대화
- 안경 마이크: 사용자가 누르면 녹음 시작, 다시 누르면 끝(최대 60초) → `https://api.geol2.com/api/ai/transcribe`로 보내 받아쓰기 → 결과 글자만 질문으로 사용 (녹음은 서버 임시 폴더에서 whisper로 받아 적은 직후 삭제, 외부 서비스로 보내지 않음)
- 기기에만 저장하는 데이터: 인증 토큰, 플래시카드 복습 기록
- Even 앱의 카메라·사진첩·위치·IMU 권한은 쓰지 않음 (사진은 사용자가 폰·PC 화면에서 직접 파일을 골라 첨부할 때만 보냄 — 아래 Anthropic 항목)

### 제3자 제공: Anthropic (AI 답변) — 처리방침에 넣을 문안

```
■ AI 답변을 위한 정보 제공 (Anthropic)

'Claude에게 묻기' 기능을 쓰면, 답변을 만들기 위해 아래 정보가 달빛 서랍 서버(api.geol2.com)를 거쳐 Anthropic, PBC(미국)의 Claude로 전송됩니다. 앱이 Anthropic에 직접 접속하지는 않습니다.

- 보내는 정보
  · 질문 내용(직접 입력한 글, 또는 음성을 받아 적은 글)
  · 같은 대화의 최근 질문과 답(최대 10개)
  · 질문에 첨부한 사진(최대 6장)
  · 프로젝트를 고르고 물은 경우, 답변에 필요해 Claude가 읽은 그 프로젝트의 파일 내용(사용자가 올린 zip 또는 연결한 GitHub 저장소)
- 보내지 않는 정보
  · 녹음된 음성 — 음성은 달빛 서랍 서버에서 받아 적은 직후 지우며, Anthropic에 보내지 않습니다.
  · 이메일·비밀번호 등 계정 정보, 할 일·메모(질문에 직접 적은 경우 제외)
- 목적: 질문에 대한 답변 생성
- 처리 방식: 서버의 Claude Code(구독 계정)로 먼저 답하고, 사용 한도에 걸리면 Claude API로 답합니다. 두 경우 모두 Anthropic이 처리합니다.
- Anthropic의 보관·이용: Anthropic 개인정보 처리방침(https://www.anthropic.com/legal/privacy)을 따릅니다.
- 이 기능은 허용된 계정에서만 켜지며, 쓰지 않으면 아무 정보도 Anthropic에 보내지 않습니다.
```

> 제출 전 확인: 서버의 Claude Code가 **개인(소비자) 구독 계정**이면, Anthropic 소비자 약관의 "모델 학습에 대화 사용" 설정에 따라 대화가 학습에 쓰일 수 있습니다. 계정 설정을 확인하고, 켜져 있으면 끄거나 처리방침에 그 사실을 적으세요. API 경로는 Anthropic 상업 약관을 따릅니다.
